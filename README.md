# LaTeX Learning Journey

A beginner-friendly collection of LaTeX examples and learning materials, arranged in modules. The repository starts with the basic building blocks of a LaTeX document and gradually moves into mathematics, tables and figures, document styling, and slide presentations.

## Modules

| Module | Topics | Materials |
|---|---|---|
| [01 – Basics of LaTeX](01-Basics/README.md) | First document, text formatting, headings, sections, and lists | LaTeX examples and compiled PDF |
| [02 – Mathematics](02-Mathematics/README.md) | Inline and display math, powers and subscripts, fractions, roots, Greek letters, operators, equations, alignment, and matrices | Explanation source and compiled examples |
| [03 – Tables, Color, and Figures](03-Tables-and-Color-and-Figures/README.md) | Tables, color, images, figure placement, captions, labels, references, and TikZ | LaTeX source and compiled PDF |
| [04 – Document and Page Styles](04-Document-and-Page-Styles/README.md) | Document classes, titles, abstracts, margins, page styles, headers and footers, spacing, text boxes, and BibTeX | LaTeX examples, PDFs, and bibliography |
| [05 – Beamer Presentations](05-Beamer-Presentations/README.md) | Beamer document class, title slides, frames, lists, equations, spacing, and presentation structure | Beamer source and compiled presentation |

## Suggested Learning Order

Work through the modules in numerical order. Each module focuses on a different part of the LaTeX workflow:

1. Start with the syntax and structure of a basic document.
2. Practise writing mathematical expressions.
3. Learn to create tables, add color, and include figures.
4. Customize page layout and document appearance.
5. Use Beamer to prepare presentation slides.

## Getting Started

You can edit and compile the examples with [Overleaf](https://www.overleaf.com/) or with a local LaTeX distribution such as TeX Live or MiKTeX.

A typical workflow is:

1. Open the `.tex` file for the topic you are studying.
2. Read the comments and try changing the example.
3. Compile the source to generate a PDF.
4. Compare the output with the example PDF provided in that module, when available.

Use the compilation notes inside each module for any package-specific or bibliography-related steps.
