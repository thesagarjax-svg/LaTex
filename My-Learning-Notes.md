## 1. Introduction

- LaTeX is used to prepare well-formatted documents.
- LaTeX source files usually have the `.tex` extension.
- A LaTeX source file is compiled to create a PDF or another output format.

## 2. Basic Document Structure

A simple LaTeX document contains a document class, a preamble, and a document body.

```latex
\documentclass{article}

\begin{document}
Hello, LaTeX!
\end{document}
```

- `\documentclass{article}` selects the document type.
- The preamble is written before `\begin{document}`.
- `\begin{document}` starts the document body.
- `\end{document}` finishes the document.

## 3. Commands I Have Practised

| Command | Purpose |
|---|---|
| `\title{}` | Sets the document title |
| `\author{}` | Sets the author |
| `\date{}` | Sets the date |
| `\maketitle` | Displays the title information |
| `\section{}` | Creates a section |
| `\textbf{}` | Makes text bold |
| `\textit{}` | Makes text italic |
| `\underline{}` | Underlines text |

## 4. Things to Remember

- LaTeX commands generally begin with a backslash.
- Curly braces contain required command arguments.
- Environments should have matching begin and end commands.
- Package commands belong in the preamble.
- Read compiler error messages carefully and check spelling and braces.
