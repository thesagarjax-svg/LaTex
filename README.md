# My LaTeX Learning Journey

Welcome to my **LaTeX Learning Journey**! This repository contains the notes, examples, and practice work I create while learning LaTeX step by step.

I am starting with the basics and gradually practising document formatting, mathematical equations, lists, tables, and small projects. The examples are written for learning and can be modified and compiled to understand how LaTeX works.

## About LaTeX

LaTeX is a document preparation system commonly used for academic documents, assignments, reports, and documents that contain mathematical expressions. Instead of formatting everything manually, we write commands in a `.tex` file and compile it to produce a formatted document.

## What I Am Learning

- Introduction to LaTeX and its basic structure
- Document classes, title, author, and sections
- Basic commands and text formatting
- Ordered and unordered lists
- Mathematical expressions and equations
- Tables and captions
- How to include images in a LaTeX document
- Creating small documents using the concepts I learn

## How to Try the Examples

1. Open [Overleaf](https://www.overleaf.com/) or use a local LaTeX installation.
2. Create a new project or upload one of the `.tex` files from this repository.
3. Select pdfLaTeX as the compiler unless the example says otherwise.
4. Compile the file to view the PDF.
5. Change the text or commands and compile again to practise.

## Mini Projects

The mini-project folder contains three beginner exercises:

1. **Student Profile** — practise titles, sections, paragraphs, and lists.
2. **Mathematics Assignment** — practise fractions, equations, powers, and matrices.
3. **Student Marks Report** — practise tables, captions, and simple report structure.
