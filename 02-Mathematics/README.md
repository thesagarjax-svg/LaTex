# Mathematics in LaTeX

This folder is a beginner-friendly introduction to writing mathematics in LaTeX.

## Learning materials

- **[explanation.tex](explanation.tex)** — definitions and explanations of all eight topics, with LaTeX source commands, expected results, command descriptions, and practice exercises.
- **[compiled_output.pdf](compiled_output.pdf)** — rendered mathematical examples for all eight topics. This PDF contains examples only, not LaTeX source code.

## Topics covered

1. Inline and display mathematics
2. Superscripts and subscripts
3. Fractions and roots
4. Greek letters
5. Mathematical operators
6. Brackets and grouping
7. Equations and alignment
8. Matrices

## How to study

1. Read a topic in `explanation.tex`.
2. Try typing its LaTeX source in Overleaf or another LaTeX editor.
3. Compile your document.
4. Compare your result with `compiled_output.pdf`.
5. Complete the practice task at the end of the topic.

**Note:** The examples using `align*` and `bmatrix` require `\usepackage{amsmath}` in the document preamble.
