# 02 – Mathematics

This section introduces mathematical typesetting in LaTeX from the beginning. Each lesson follows the same order:

1. **Explanation** – what the concept means.
2. **LaTeX source code** – what to type.
3. **Expected compiled output** – how it should look in the PDF.
4. **Step-by-step explanation** – what the commands and symbols do.
5. **Practice** – a short task to try yourself.

## How to use these lessons

1. Open a lesson's `.tex` file and read the explanation.
2. Type or copy its source into a LaTeX editor such as Overleaf.
3. Compile the document to see the rendered result.
4. Compare your result with the expected output shown in the lesson.
5. Try the practice task without looking at the example.

For lessons using `align*`, `bmatrix`, or other advanced math environments, include `\\usepackage{amsmath}` in the document preamble.

## Practice checklist

- [ ] I can write inline and display maths.
- [ ] I can write superscripts and subscripts.
- [ ] I can create fractions and roots.

- [ ] I can use common mathematical operators.

- [ ] I can align multiple equations.

**Tip:** The code in each lesson is LaTeX source. The mathematical expressions shown as expected output are what you should see after compiling it.
