# Module 05: Creating Presentations with Beamer

This module introduces LaTeX Beamer, a document class designed for preparing slide presentations. It covers the basic structure of a slide deck, adding content to frames, presenting equations, and arranging information clearly for an audience.

## Files

- `basic-presentation.tex` — LaTeX source for the Beamer slide deck.
- `basic-presentation.pdf` — Compiled presentation ready to view or present.

## Topics Covered

- Getting started with the Beamer document class
- Setting up presentation title, author, date, and institute details
- Creating an opening slide with `\titlepage`
- Building individual slides with the `frame` environment
- Adding titles to slides
- Presenting bullet points and nested lists
- Including mathematical expressions and equations
- Using vertical spacing to organize slide content
- Preparing a final slide to close the presentation

## Compilation

Open the `.tex` source in Overleaf or a local LaTeX editor that supports Beamer. Compile the file with pdfLaTeX to generate the presentation PDF. Beamer is included in common LaTeX distributions.

## Theme

The presentation is designed around a clean academic style, with clear slide titles, readable text, and a consistent visual layout. Beamer themes and color settings can be changed in the preamble to give the slides a different appearance.
