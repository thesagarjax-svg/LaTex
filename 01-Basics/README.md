# 01 – Basics of LaTeX

Welcome to your first LaTeX lesson! This section is designed for complete beginners. No previous experience is needed.

## What is LaTeX?

LaTeX is a document preparation system. You write instructions in a text file, and LaTeX converts them into a professionally formatted document, usually a PDF.

## How does it work?

Write a `.tex` file → Compile it → View the PDF.

## Where can I practise?

You can use [Overleaf](https://www.overleaf.com/), an online LaTeX editor.

1. Create a free account.
2. Choose **New Project → Blank Project**.
3. Open the `.tex` file and enter the example.
4. Click **Recompile** to see the PDF.

## Lessons in this folder

- `introduction.tex` — Your first LaTeX document.
- `text_formatting.tex` — Bold, italic, underline and monospaced text.
- `headings_and_sections.tex` — Titles, sections and subsections.
- `lists.tex` — Bullet-point and numbered lists.
- `compiled_output.pdf` — Rendered document output, without source code.

## Practice

- Change the document title and author.
- Add a sentence to a section.
- Create another subsection.
- Add more items to each list.
- Recompile and observe the changes.

**Note:** The `.tex` files contain editable LaTeX source. The PDF is for viewing the rendered result only. This first lesson does not cover mathematics or equations.
